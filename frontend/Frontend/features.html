WHAT OUR SYSTEM OFFERS

Everything You Need to Report Road Hazards

Smart Road Hazard System brings important road reporting capabilities together. From capturing evidence to organising complaints, each feature is designed to make road hazard reporting easier and more informative.

📸
FEATURE 01

Photo Capture & Upload

Capture a photograph or upload an existing image of potholes, broken roads, damaged footpaths, open manholes or other road hazards. Visual evidence helps explain the problem clearly.

  • Capture or select road images
  • Show visible damage as evidence
  • Attach images to a complaint
Use Feature →
📍
FEATURE 02

GPS Location Sharing

Add the location where a road hazard exists. GPS coordinates or a manually entered address can help identify the affected area and reduce confusion about where repairs are needed.

  • Share location coordinates
  • Enter an address manually
  • Identify the reported road section
Use Feature →
📝
FEATURE 03

Online Complaint Registration

Create a structured complaint by describing the road problem and providing relevant evidence. A well-organised report makes the issue easier for reviewers to understand.

  • Describe the road issue
  • Select a hazard category
  • Submit complaint details
Use Feature →
📋
FEATURE 04

Complaint Status Tracking

Check the progress of submitted complaints when status tracking is available. This helps users understand whether a report is awaiting review or has been updated.

  • View submitted complaints
  • Check pending and reviewed reports
  • See available resolution updates
Use Feature →
🔔
FEATURE 05

Complaint Notifications

Notifications can keep users informed when a complaint is received, reviewed or updated. They reduce the need to repeatedly check for changes manually.

  • Submission confirmation
  • Complaint status alerts
  • Updates when a report changes
Use Feature →
👤
FEATURE 06

User Account & Report History

A user account can keep reports organised under one profile. Users can revisit their submissions and manage their reporting activity.

  • User registration and login
  • Personal complaint history
  • Access to previous submissions
Use Feature →
🗺️
FEATURE 07

Road Hazard Map

A map-based view can display reported road hazards at their recorded locations. It can help users understand where issues exist and support location-based review.

  • View reported hazard locations
  • Explore affected areas
  • Filter reports by location or category
Use Feature →
⚠️
FEATURE 08

Hazard Severity & Priority

Classify hazards according to their type and potential seriousness. A large pothole on a busy road may need more urgent attention than minor surface damage.

  • Identify different hazard types
  • Highlight serious road conditions
  • Support repair prioritisation
Use Feature →
📊
FEATURE 09

Admin Dashboard & Analytics

An administrative dashboard can organise complaints and present useful statistics. It can help authorised staff review reports and monitor road safety issues.

  • Review submitted complaints
  • Organise reports by status
  • View hazard and resolution statistics
